Development of an automated steering system

February–June 2025 · Student project · DUT Applied Physics

The goal of this project was to build a miniature boat capable of navigating an obstacle course autonomously and as quickly as possible.

My role was to develop an autonomous steering system for the vehicle.

I built a sonar system using a servo motor, an ultrasonic sensor, a LiDAR sensor and an Arduino Nano. I made the necessary connections and programmed the Arduino to operate the system.

Switching between ultrasonic and LiDAR measurements made it possible to adapt speed and accuracy to the distance of each detected obstacle.
